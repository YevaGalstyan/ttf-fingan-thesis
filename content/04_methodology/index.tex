\section{Methodology and Implementation}\label{sec:methodology}

This chapter describes how the data is prepared, how the models are trained and evaluated, and how option prices are computed from the generated returns. 

Two datasets are used. The TTF futures data covers January 2010 to April 2026 and provides the daily front-month returns. On this dataset the model is trained and evaluated. The TTF options data provides the market prices and implied volatilities over the test period. The model follows the ForGAN architecture and the reference Fin-GAN implementation \parencite{vuleticFinGANForecastingClassifying2024}. Ten cost function branches are trained. The first is the ForGAN baseline, trained on cross-entropy alone. The other nine are Fin-GAN branches that add the economics-driven terms of Sec.~\ref{sec:fin-gan}. Each branch is trained under ten network and training configurations and one input scaling run, with five seeds each. The selected model generates price paths for pricing call options on \num{20} valuation dates, and GBM and two bootstrap modes serve as benchmarks.

Sec.~\ref{sec:data-pipeline} constructs the daily TTF front-month return series from the futures data and splits it into training, validation, and test splits. It also prepares the options data that provides the market reference. Sec.~\ref{sec:model} describes the model architecture, the training setup, and the adaptations to the reference Fin-GAN implementation. Sec.~\ref{sec:configurations} defines the configurations and the cost function branches. Sec.~\ref{sec:evaluation} describes how the generated returns are compared with the test split. Sec.~\ref{sec:pricing-setup} describes how the selected model generates price paths by recursive rollout and how call options are priced from these paths. Sec.~\ref{sec:benchmarks} introduces the benchmark models, Sec.~\ref{sec:software} lists the software environment, and Sec.~\ref{sec:method-summary} summarizes the setup.
