All configurations are trained with five fixed seeds, and the values are reported as mean and seed spread. The seed range of a value is its mean plus or minus one seed spread. The difference between configurations or cost function branches is treated as separable if their seed ranges do not overlap. A generated value is treated as separable from the test split if its seed range does not contain the realized value. A configuration or cost function is treated as closer to the test split if its seed ranges are narrower and contain the realized value on more statistics.

Sec.~\ref{sec:properties-ttf} reports the properties of the realized TTF return series. Secs.~\ref{sec:baseline}--\ref{sec:condition-window} report the ForGAN baseline across training lengths, network capacities, condition windows, and input scaling. Sec.~\ref{sec:effect-cost} reports the effect of the cost function terms under configuration 8. Sec.~\ref{sec:model-selection} selects the model for pricing, Sec.~\ref{sec:option-prices} reports the option prices, and Sec.~\ref{sec:results-summary} summarizes the results. Each section reports a defined slice of the full experimental grid from App.~\ref{app:grid}.
