\section{Full Experimental Grid}\label{app:grid}
\captionsetup[table]{list=no}
This appendix reports the generated returns of all ten cost function branches, listed in Sec.~\ref{sec:configurations}. 
Each of the ten configurations of Table~\ref{tab:configurations} and the input scaling run is reported with all ten branches. Every combination was trained with five seeds, and the values are reported as mean and seed spread. Each configuration is reported in three tables: distributional statistics, tail statistics, and the autocorrelation of squared returns at $\tau=1,2,5,10$. The reference values of the test split are reported in Table~\ref{tab:ttf-stats}. The first column of each table enumerates the ten cost function branches as listed in Table~\ref{tab:branch_key}. Kurt denotes the excess kurtosis, $q_{1}$ and $q_{99}$ the \SI{1}{\percent} and \SI{99}{\percent} quantiles, and $P_{0.05}$ and $P_{0.10}$ the fractions $P(|x| > 0.05)$ and $P(|x| > 0.10)$.
