\section{Point Forecast Metrics}\label{app:point-forecast}

This appendix reports the point forecast metrics of Sec.~\ref{sec:evaluation} for all ten cost function branches under configuration 8. Every combination was trained with five seeds, and the values are reported as mean and seed spread. The metrics are computed from the mean set $m$ against the realized
returns of the test split. The point forecast metrics are not the criterion of this thesis and are reported for comparability with the equity results of \textcite{vuleticFinGANForecastingClassifying2024}. The first column enumerates the ten cost function branches as listed in Table~\ref{tab:branch_key}.
